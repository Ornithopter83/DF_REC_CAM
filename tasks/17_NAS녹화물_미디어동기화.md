# 작업명

NAS 녹화물 미디어 동기화 안정화

## 목표

NAS의 완성된 대용량 MP4를 비공개 Supabase Storage에 멱등적으로 올리고, 중단 이후에도 TUS 업로드를 안전하게 이어서 완료할 수 있게 한다.

## 예정 구현 범위

* A. NAS 파일 발견, 안정화 판정, 업로드 대상 선정과 중복 방지를 정리한다.
* B. TUS 업로드 위치 저장, 재시작·네트워크 복구 후 이어올리기와 만료 처리를 보완한다.
* C. Storage 실제 길이 검증, 완료 상태 전환과 전역 파일 크기 제한의 사전 오류 처리를 정리한다.
* D. 실패·취소·중단 업로드의 상태와 정리 경계를 보완하고 웹 목록 반영까지 연결한다.

## 진행 현황

잔여 작업 4개 (A, B, C, D)

* 16번 작업 완료 후 현재 구현을 다시 분석해 세부 완료 조건을 확정한다.
* 진행 중 새로 발견한 해결 과제는 별도 지시 대상으로 분리한다.

## 결과

* 작업 완료 후 갱신한다.
