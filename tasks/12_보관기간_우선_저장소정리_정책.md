# 작업명

보관기간 우선 저장소 정리 정책

## 목표

* 녹화 파일은 설정된 보관 기간이 지난 경우에만 자동 삭제한다.
* `MaxStorageGB`와 `MinFreeDiskGB`에 따른 보관기간 무시 강제 삭제를 제거한다.
* 디스크 사용률 임계치에서는 기존처럼 신규 녹화만 중단·재개한다.

## 원인

* 저장소 정리가 `REC` 아래 모든 확장자의 크기를 계산하면서 삭제 후보는 MP4로만 제한했다.
* `REC` 안의 ZIP 백업만으로 50GB 제한을 초과하면 용량 조건을 충족할 수 없어 보관 기간이 남은 MP4까지 모두 삭제할 수 있었다.
* 시작 정리가 설정에 따른 호출 이후 한 번 더 무조건 실행되고 있었다.

## 구현 기준

* 날짜 기반 `DeleteOldFiles()` 정리는 유지한다.
* `EnforceStorageLimit()`과 `DeleteUntilOk()` 강제 삭제 경로를 제거한다.
* `DiskStopThresholdPercent`와 `DiskResumeThresholdPercent`에 따른 녹화 중단·재개는 유지한다.
* 기존 `settings.json` 호환을 위해 `MaxStorageGB`와 `MinFreeDiskGB` 필드는 유지하되 삭제 정책에서는 사용하지 않는다.
* 시작 시 정리는 `CleanupOnStartup=true`일 때 한 번만 실행한다.

## 완료 조건

* 보관 기간이 남은 MP4는 REC 용량이나 디스크 여유 공간 때문에 삭제되지 않는다.
* ZIP 등 비녹화 파일이 REC에 있어도 MP4 강제 삭제가 발생하지 않는다.
* 디스크 사용률 중단·재개 정책이 유지된다.
* 빌드가 경고와 오류 없이 완료된다.

## 테스트 방법

* 보관 기간 이내 및 초과 MP4를 준비하고 정리 후 초과 파일만 삭제되는지 확인한다.
* REC에 50GB 이상의 비MP4 파일이 있어도 보관 기간 이내 MP4가 유지되는지 확인한다.
* 디스크 사용률 중단·재개 코드가 그대로 유지되는지 정적으로 확인한다.

## 결과

* `MaxStorageGB`와 `MinFreeDiskGB`를 기준으로 MP4를 추가 삭제하던 용량 강제 삭제 경로를 제거했다.
* 기존 설정 파일과 공개 모델의 호환성을 위해 두 설정 필드는 유지하지만 저장소 정리에는 사용하지 않는다.
* 일반 녹화 폴더 정리에서 `events`, `manual`, `temp` 하위 폴더를 제외하여 각각의 보관기간이 다른 정책으로 덮어써지지 않게 했다.
* 디스크 사용률에 따른 신규 녹화 중단·재개는 파일을 삭제하지 않는 안전장치로 유지했다.
* 시작 시 무조건 실행되던 중복 정리를 제거하여 `CleanupOnStartup` 설정에 따른 예약 정리만 한 번 실행되게 했다.
* `dotnet build DFBlackbox\DFBlackbox.csproj -o .buildcheck` 결과 경고 0개, 오류 0개로 완료했다.
* 정적 검색 결과 `EnforceStorageLimit`과 `DeleteUntilOk` 호출 및 구현이 남아 있지 않음을 확인했다.
