# 작업명

공유 인코딩 기반 녹화·송출 동시성 안정화

## 목표

단일 H.264 인코딩 결과를 MP4 녹화와 실시간 송출이 공유하면서도 각 소비자의 지연·시작·중지·실패가 서로의 수명주기에 영향을 주지 않게 한다.

## 예정 구현 범위

* A. 인코더, 녹화 sink, 송출 sink의 큐·프레임·프로세스 소유권을 정리한다.
* B. 녹화 우선 backpressure와 송출 제한 큐의 독립성을 보완한다.
* C. 송출 시작·중지 중에도 프리버퍼, 파일 분할, MP4 종료 처리가 유지되게 한다.
* D. 취소·오류·앱 종료 시 리소스 정리와 녹화 회귀를 확인하고 보완한다.

## 진행 현황

잔여 작업 4개 (A, B, C, D)

* 15번 작업 완료 후 현재 구현을 다시 분석해 세부 완료 조건을 확정한다.
* 진행 중 새로 발견한 해결 과제는 별도 지시 대상으로 분리한다.

## 결과

* 작업 완료 후 갱신한다.
