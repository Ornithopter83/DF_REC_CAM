# 작업명

프로젝트 문서 최신화, 이주 요약과 Word 구성 가이드

## 목표

현재 코드·배포 상태와 어긋난 프로젝트 문서를 최신 정책으로 통합하고, 새 스레드가 바로 작업을 이어갈 수 있는 요약과 운영자가 사용할 Word 구성 가이드를 만든다.

## 세부 작업

* A. 코드, 배포 설정, 작업서와 기존 문서의 불일치를 감사한다. (완료: 2026-08-14)
* B. 현재 상태, README, Supabase·NAS·API 문서와 이주 요약을 최신화한다. (완료: 2026-08-14)
* C. 문서 변경을 검증해 `스트리밍` 브랜치에 커밋·푸시한다. (완료: 2026-08-14)
* D. 프로젝트 구성 요소와 구성 가이드를 Word로 작성하고 렌더링·시각 검증한다. (완료: 2026-08-14)

## 진행 현황

잔여 작업 0개

## 정책·보안 경계

* 실제 비밀값, 장치 토큰, NAS 계정 정보와 개인키를 문서에 기록하지 않는다.
* 배포된 레거시 DB 객체와 과거 작업 결과를 삭제하거나 역사 기록을 왜곡하지 않는다.
* Word 가이드는 설정 항목명·입력 위치·검증 방법을 설명하되 운영 값은 자리표시자로만 제시한다.

## 결과

* A: `CurrentWork.md`, `NewThreadHandoff.md`, `README.txt`, Supabase·NAS·recording-media README가 `main`, 미적용 DB, Storage/TUS 업로드와 녹화본 웹 재생 등 과거 상태를 담고 있음을 확인했다.
* B: 문서를 `스트리밍`, 원격 마이그레이션 001~015, NAS HTTPS 이어올리기, LiveKit 실시간 전용 재생, NAS SSO 다운로드와 신규 등록명·공백 정책 기준으로 갱신했다.
* C: 주요 문서에서 과거 `main`, 미적용 DB, 신규 Storage/TUS 업로드와 녹화본 웹 재생 주장을 제거하고 diff 공백 검사를 통과했다.
* D: `docs/DFBlackbox_프로젝트_구성_및_설정_가이드.docx`를 compact reference guide 형식으로 작성했다. 구성 요소, 데이터 흐름, 데스크톱·Supabase·LiveKit·NAS·웹 설정, 신규 PC 등록, 검증·장애 대응과 보안 경계를 포함한다.
* D: DOCX ZIP·OOXML 재열기, Letter/1인치 여백, 스타일 토큰, 19개 표의 9360 DXA 고정 geometry, 9개 데이터 표의 반복 헤더, 75개 실제 번호 목록과 비밀값 노출 검사를 통과했다. 접근성 감사의 중간 경고 10개는 제목 행이 필요 없는 1행 callout 표에 한정됐다.
* D: 기본 LibreOffice 렌더러는 실행 파일이 없어 사용할 수 없었고 설치된 Word의 자동 PDF 내보내기도 환경 문제로 중단됐다. 따라서 페이지 PNG 시각 QA는 완료하지 못했으며 구조 검증 결과만 확정했다.
