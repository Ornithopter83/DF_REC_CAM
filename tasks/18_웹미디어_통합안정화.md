# 작업명

웹 미디어 통합 안정화와 릴리스 정리

## 목표

실시간 시청과 녹화 목록·재생·다운로드를 공통 권한 및 오류 경계로 정리하고, 데스크톱·Edge Function·웹의 구현 결과를 통합해 릴리스 가능한 상태로 마무리한다.

## 예정 구현 범위

* A. 실시간 플레이어와 녹화 목록·재생·다운로드의 사용자 상태 및 오류 처리를 정리한다.
* B. 데스크톱·Edge Function·웹 간 인증, 권한, signed URL과 오류 응답 규약을 보완한다.
* C. 15~17번에서 확인된 통합 결함만 수정하고 전체 실제 흐름의 회귀를 정리한다.
* D. Release 빌드, publish, 웹·Edge 검사, 문서 갱신과 검증된 변경의 커밋·푸시를 수행한다.

## 진행 현황

잔여 작업 4개 (A, B, C, D)

* 17번 작업 완료 후 현재 구현을 다시 분석해 세부 완료 조건을 확정한다.
* 진행 중 새로 발견한 해결 과제는 별도 지시 대상으로 분리한다.

## 결과

* 작업 완료 후 갱신한다.
