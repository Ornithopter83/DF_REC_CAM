# 작업명

웹 미디어 통합 안정화와 릴리스 정리

## 목표

실시간 시청과 녹화 목록·NAS 다운로드를 공통 권한 및 오류 경계로 정리하고, 데스크톱·Edge Function·웹의 구현 결과를 통합해 릴리스 가능한 상태로 마무리한다. 웹 내 영상 재생은 LiveKit 실시간 스트리밍만 제공한다.

## 예정 구현 범위

* A. 실시간 플레이어와 녹화 목록·NAS 다운로드의 사용자 상태 및 오류 처리를 정리하고 녹화본 웹 재생 UI를 제거한다. (완료: 2026-08-14)
* B. 데스크톱·Edge Function·웹 간 인증, 권한, NAS 식별자·상대 경로와 오류 응답 규약을 보완한다. (완료: 2026-08-14)
* C. 15~17번에서 확인된 통합 결함만 수정하고 전체 실제 흐름의 회귀를 정리한다. (완료: 2026-08-14)
* D. Release 빌드, publish, 웹·Edge 검사, 문서 갱신과 검증된 변경의 커밋·푸시를 수행한다. (완료: 2026-08-14)

## 진행 현황

잔여 작업 0개

* 17번 작업 완료 후 현재 구현을 다시 분석해 세부 완료 조건을 확정한다.
* 진행 중 새로 발견한 해결 과제는 별도 지시 대상으로 분리한다.

## 결과

* A: 녹화본 `<video>`와 재생 URL 요청을 제거하고 카메라별 NAS 녹화 목록·다운로드 선택 화면으로 정리했다. 실시간 `<video>`는 LiveKit 전용으로 유지한다.
* B: DB에 조직별 NAS 위치, 카메라 NAS 루트와 녹화 상대 경로를 추가했다. Edge Function은 조직 권한 확인 후 HTTPS NAS 다운로드 주소만 반환하고 웹은 HTTPS·무자격증명 주소만 새 탭으로 연다.
* C: 녹화 목록·다운로드는 장치 폴링이나 LiveKit lease를 요구하지 않아 PC가 오프라인이어도 DB와 NAS가 접속 가능하면 동작한다. 실시간 보기는 기존 요청형 lease 흐름만 사용한다.
* 009·010 마이그레이션을 원격 적용하고 `recording-media`를 배포했다. 제거된 업로드 경로 404, 사용자 무인증 목록·다운로드 401, 잘못된 장치 토큰의 카탈로그 등록 401을 확인했다.
* 실제 카메라가 없어 WebRTC 종단 간 영상, 녹화 중 송출 동시성, 네트워크 차단 후 재게시는 운영 장비 검증으로 남긴다.
* D: 최종 Release 빌드 경고 0개·오류 0개와 self-contained publish를 통과했다. 웹 JavaScript 구문, HTML ID 계약, 녹화 재생·Storage/TUS 잔존 경로와 diff 공백 검사를 통과했다.
* 원격 마이그레이션 001~010 이력이 일치하고 `recording-media` 버전 6이 ACTIVE임을 확인했다.
