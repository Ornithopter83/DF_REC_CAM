# 작업명

USB 카메라 속성 capability 조회 및 실시간 제어 팝업

## 목표

* USB 카메라가 실제 지원하는 속성과 범위를 읽어 팝업에 표시한다.
* 지원 항목만 활성화하고 변경값을 영상에 즉시 반영한다.
* 적용 시 확정하고 취소 또는 창 닫기 시 팝업을 열기 전 상태로 복원한다.

## 관련 파일

* `DFBlackbox/Core/CameraService.cs`
* `DFBlackbox/Core/UsbCameraPropertySession.cs`
* `DFBlackbox/Forms/CameraSettingsForm.cs`
* `DFBlackbox/Forms/MainForm.cs`
* `DFBlackbox/Forms/MainForm.Designer.cs`
* `DFBlackbox/Utils/Localization.cs`

## 요구사항

* 팝업은 USB 카메라가 열린 상태에서만 진입할 수 있다.
* `IAMCameraControl`과 `IAMVideoProcAmp.GetRange()`로 지원 여부, 최소·최대·단계·기본값, 자동·수동 지원 여부를 조회한다.
* 노출, 게인, 밝기, 대비, 채도, 화이트밸런스, 초점을 기본 항목으로 제공한다.
* 지원하지 않는 항목은 비활성화하고 `미지원`으로 표시한다.
* 값과 자동 모드 변경은 장치에 즉시 반영한다.
* 적용 시 현재 값을 설정에 저장하고, 취소 또는 X 닫기 시 원래 값과 자동·수동 모드를 복원한다.
* 카메라 제어 COM 객체는 팝업 종료 시 해제한다.

## 완료 조건

* 카메라를 열기 전에는 속성 버튼을 사용할 수 없다.
* 장치별 지원 항목과 범위가 올바르게 구분된다.
* 적용한 값은 유지되고 취소한 값은 원래 상태로 돌아간다.
* KOR/ENG 문구가 모두 제공된다.
* 빌드가 경고와 오류 없이 완료된다.

## 테스트 방법

* USB 카메라를 열기 전과 연 후 속성 버튼 활성화 상태를 확인한다.
* 지원·미지원 속성 표시와 최소·최대·단계값을 장치 기본 속성창과 비교한다.
* 노출, 밝기, 초점 등을 변경해 프리뷰에 즉시 반영되는지 확인한다.
* 적용 후 다시 열었을 때 값이 유지되는지 확인한다.
* 취소 및 X 닫기 후 원래 값으로 복원되는지 확인한다.
* `dotnet build DFBlackbox\DFBlackbox.csproj -o .buildcheck`를 실행한다.

## 결과

* 영상 캡처는 성능 회귀를 피하기 위해 기존 OpenCV 자동 백엔드 선택을 유지하고, DirectShow는 팝업 생존 중 capability 조회와 속성 적용에만 사용한다.
* `IAMCameraControl`과 `IAMVideoProcAmp` 기반 속성 세션을 추가했다.
* 지원 범위와 자동·수동 플래그를 기반으로 편집기 활성화 상태를 결정하도록 팝업을 재구성했다.
* 변경값은 즉시 장치에 적용하고, 적용 시 설정 저장, 취소 및 X 닫기 시 최초 값 복원을 구현했다.
* 카메라 속성 버튼을 카메라 상태 카드에 배치하고 카메라가 열린 동안에만 활성화했다.
* `dotnet build DFBlackbox\DFBlackbox.csproj -o .buildcheck` 결과 경고 0개, 오류 0개로 성공했다.
* 실제 장치별 capability와 실시간 반영 여부는 USB 웹캠으로 수동 확인이 필요하다.
* DirectShow 캡처 강제 지정 시 실제 프레임이 크게 낮아지는 장치가 확인될 수 있어 영상 캡처 백엔드 강제 지정은 제거했다. 속성 팝업은 상시 폴링하지 않는다.
* 지원 속성은 장치가 제공한 최소값·최대값을 슬라이더 양쪽에 표시하고, 슬라이더와 숫자 입력을 증분값 단위로 동기화하도록 개선했다.
* 자동 열은 중앙 체크박스만 표시하고 자동·지원 여부 열 폭을 줄여 속성 슬라이더가 더 긴 가로 공간을 사용하도록 조정했다.
